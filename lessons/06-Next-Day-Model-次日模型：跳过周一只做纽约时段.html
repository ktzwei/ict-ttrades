"Next Day Model" The MMXM Trader（次日模型）— 中英对照学习笔记

来源：TTrades — *"Next Day Model" The MMXM Trader - ICT Concepts*（13:35）
概念定位：本集讲 TTrades 分享的 MMXM（Next Day）模型——一套"跳过周一、只做纽约时段、15分钟图、用经济日历当路线图、在前高周期（HTF）位被触及后的次日进场"的系统打法。核心是把"什么时候该看盘"和"看哪个周期"彻底固定下来。

---

一、核心思想（先看这个）

作者开场点题：这是 MMXM 在 Twitter 上发的模型，TTrades 用自顶向下（top-down analysis）拆解它：

这套模型包括：跳过周一（skipping Mondays）、只做纽约时段（New York session only）、在15分钟图执行（executing on the 15-minute chart）、用经济日历当路线图（economic calendar as your roadmap）、以及在你预期的高周期位（HTF level）被触及之后的次日交易（trading the day after）。

关键逻辑链：

1. 先在日线（daily）上找到 DOL（draw on liquidity 流动性目标），比如日线 FVG、日线订单块。

2. 周一跳过——周一是"偷取前日高点、收回区间"的洗盘日，不做。

3. 等价格触及那个高周期位（前日/前周高点、日线 FVG/OB），拿到反应（reaction）。

4. 次日在 15 分钟图找纽约时段的 setup：通常是"回踩 15m FVG / 老高点 / 订单块，然后位移去扫流动性"。

5. 只做纽约 AM 时段，错过就让下一集/次日再来。

一句话记住：周日线定方向，周一不碰，等高周期位被打到、次日纽约时段 15 分钟图回踩 FVG/订单块顺势进场，扫向那坨还没吃的流动性。

看日线图，我们有一个日线公允价值缺口（fair value gap）作为我们的流动性目标（draw on liquidity，DOL），就像这里标注的。然后上方还有一个日线公允价值缺口。这里就是周一。所以跳过它，我们看周二。价格向上触及我们的高周期位。现在，在我们从这个日线位拿到一个漂亮的反应（reaction）之后，我期待周三日线继续走低，吃掉卖方流动性，然后去够那个流动性目标。进到小时图，你可以看到周二——这就是我们打到日线公允价值缺口、然后出现一根激进下跌大实体之前的位置。我们有一个小时线的破坏块（breaker），在我们进入周三时。价格回踩向上进入这个小时线破坏块、小时线公允价值缺口，然后离开。

看 15 分钟图，我们有午夜开盘（midnight open），那一段就是冲进小时线公允价值缺口和破坏块、然后又离开的走势。当我们进入纽约时段，这里有一个 15 分钟公允价值缺口。价格先回踩到它的后入侵（consequent encroachment，CE）区域，然后交付到周开盘（weekly open），最终交付到下方的流动性目标。这就是这套模型的一个例子。我想重申：跳过周一，等待价格触及那个高周期位，然后次日看纽约时段，15 分钟 setup 来交付价格。

4.2 本集英文语法与表达整理

这集是典型的美式交易教学口播，有几个值得学的表达：

① "我们正要去/我们将"的进行时表将来

*We are going to go over the MMXM Traders Twitter model.*
  • be going to + do 表"打算做"，口语预告接下来内容的标准说法；这里叠加 going to go over 有点口语化冗余，但很地道。

② 否定词 + 比较级/未完成（表"还没"）

*We have yet to hit previous week's low.*
  • have yet to + do = "尚未做某事"，比 haven't + done 更书面、更强调"还没到那一步"。交易里高频，表"目标还没打到"。

③ 条件句表"期望/如果"

*If I'm expecting a bullish week, I'd want to see an open, low put in before expansion higher.*
  • If + 现在时, I'd (would) want to see...：条件句 + 虚拟/委婉预期，表"如果我是这种预期，那我希望看到……"，是交易者推演思路的常见句式。

④ 设问 + 追问（教学推进）

*What do we have right here? We have some nice lows stacked right there.*
  • 先设问再回答，配合 right here / right there（"就在这"），带着听众一起看图找关键位，是 TTrades 的教学习惯。

⑤ 强调"正是/就是"的 this is where/when

*This is where we hit the daily fair value gap.*
  • This is where + 句子：强调"就是在这里发生某事"，比单纯说 we hit here 更有画面感和指向性。

⑥ 转折 + 让步：However 引出反转

*However, that does not occur.*
  • 单句 However 起头表示"但事与愿违"，口语里高频用来推翻前面预设，体现"计划赶不上变化"。

⑦ 祈使 + 具体动作序列（指令感）

*So skipping this, we look at Tuesday.* / *Let's drop down to the 15-minute chart.*
  • 现在分词作状语（skipping this）+ 祈使（let's drop down），把"跳过周一→看周二→降周期"一气呵成，节奏紧凑。

⑧ 高频动词短语：reach for / take out / run stops

  • reach for = 去够/冲向；take out = 吃掉/扫掉；run (the) stops = 扫止损。交易讲解里出现频率极高，要熟。

例 3 — NASDAQ：等高目标 + 跳过周一 + OHLC 看涨周

七、给 HYPE 实战的落地要点（结合你的 HYPE-USDT 15m 玩法）

你主要盯 HYPE-USDT 15m，这套模型可以直接内化成你的节奏表：

1. 先定"模型前提"——别天天都有机会：先在 15m/1h 上找到你预期的高周期位（前日/前周高低、1h FVG/订单块）。价格没触到它之前，今天就"跳过"，不硬找机会。这能大幅砍掉你冲动开单的次数。

2. "跳过周一"用在你的市场：加密 24h，没有真正的周一，但换日点/周末后开盘的第一段常是"套现前日高低 + 收回区间"的洗盘段。识别出这种"洗盘日"就别进场，等它把流动性偷完。

3. 只做你的"纽约时段"：对你就是北京时间 19:00-22:00（美东开盘）+ 可能的凌晨段。把看盘窗口固定死，窗口外不看、不手痒。错过开盘那一波，就等下一集，别追。

4. 用经济日历当路线图：先看当天有没有 HYPE 相关或大盘（BTC/ETH）高影响数据（CPI、FOMC、以太坊ETF 等）。有大行情日，模型里的"反应"会更暴力——把这类日子标出来优先盯。

5. DOL 先行，FVG 上车：先在 1h/日线定好 DOL（下方等低点/前低/前日低），再看 15m 有没有 FVG/订单块。15m FVG 或 CE 回踩 = 你的入场；DOL = 你的目标。 一步都不能少。

6. SMT / 无影线蜡烛 = 强势佐证：看到 HYPE 与 BTC 在同一个高点"不共振"（SMT），或出现收在高点不留影线的强K线，都是多头掌控的信号——顺势做，别逆它。

7. 流动性接力 + 制造流动性：一个 DOL 被扫，马上找下一个还没吃的位；价格在区间反复盘整时，别急着追，那是在"养"新流动性，等它被扫才动手。

8. 尊重位（respect）胜过预测：价格碰到 15m FVG/OB 收出实体尊重、或午夜/日开盘不破——这比任何指标都靠谱。被尊重的位 = 你的进场依据；破掉 = 立刻撤。 把每条线都写成"碰位后的预案"，而不是"预测位"。

建议：给 HYPE 设一张"模型检查清单"：①今天该不该做（跳过日？）②高周期位打到没？③现在是不是我的纽约窗口？④DOL 定了没？⑤15m 有没有 FVG/OB 回踩？——五问全过才开单，五问缺一就观望。这会救下你绝大多数冲动单。
