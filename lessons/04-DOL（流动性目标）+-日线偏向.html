DOL（Draw On Liquidity）+ 日线偏向（Daily Bias）— 中英对照学习笔记

来源：TTrades — *The Easiest Draw On Liquidity (DOL) - Daily Bias - ICT*（13:00）
概念定位：上一集你学会了\"流动性在哪\"（前日高/低点、摆动点、等高低点）。这一集教你怎么只用前日高点和前日低点，就画出每天的流动性目标（DOL）——这是最省事、也几乎每天都存在的流动性绘制法。核心一句话：价格只要不横盘，就往昨天的高点或低点冲。

---

一、核心思想（先看这个）

作者开场就点题：这一集讲的是最省事的流动性目标（the easiest draw on liquidity），它几乎每天都出现在市场里。

关键逻辑链：

1. 除非横盘，价格总在够昨天的高/低点 —— 只要价格不进入横盘整理（consolidation，上下都打不出去），它就会去够前日高点（PDH）或前日低点（PDL），或者两个都够。

2. 趋势 = 反复吃同一侧 —— 上涨趋势里，价格会一遍又一遍地吃掉前日高点；下跌趋势里，价格会一遍又一遍地吃掉前日低点。

3. 所以：先判断趋势方向 → 就知道今天的 DOL 是高点还是低点 —— 涨势盯 PDH，跌势盯 PDL。

4. 回到日线（daily chart）先问自己一个问题 —— \"今天价格更可能够到前日高点，还是前日低点？\" 能回答这个问题，你就有 DOL 和 Target（目标），然后就可以降到小级别（lower time frame）找入场点。

5. 判断偏好的补充工具：位移（displacement） —— 有没有位移越过前日高/低点，也能给方向偏向（bias）。

6. 只看前 3 天 —— 作者回顾前日高低点，最多往前看 3 天。

一句话记住：价格不横盘就会去够昨天的高或低——涨势反复吃前日高点，跌势反复吃前日低点；日线上先问\"今天够高还是够低\"，答案就是你的 DOL，再降到小级别找入场。

4.2 本集英文语法与表达整理

① 条件句：\"除非…否则就…\"

*Unless price is going to remain in a consolidation, it is going to reach for previous day high or previous day low.*
  • unless + 从句 = 除非……，相当于 if ... not ...。这是本集最核心的句式，用来表达\"唯一的例外\"。
  • be going to do 表\"将会做某事\"，预测性表达，比 will 更带\"依据当前状况推演\"的味道。
  • 整句：除非价格停留在横盘，否则它会去够前日高点或低点。

② 条件句：\"如果做 A，就能预期 B\"

*If price is trending up, I can anticipate previous day high being taken.*
  • if + 一般现在时，主句 + can anticipate + 名词 + being + 过去分词：这是\"预期某事会发生\"的经典结构（anticipate + 宾语 + being done）。
  • 翻译：如果价格在上涨，我就能预期前日高点被吃掉。

③ 表\"很可能\"的判断句

*We are likely to see previous day's highs being taken.*
  • be likely to do = 很可能……，比 probably 更正式、更书面，交易讲解里预测价格方向的高频表达。
  • see + 宾语 + being done = 看到某事正在/将会被做（被动进行）。

④ 教学设问（自问自答）

*What do we have? We have a fair value gap here.*
  • 讲 K 线时作者先抛出问句 What do we have?，再自己答。这种\"设问→解答\"是教学视频里引导注意力的手法，让你下意识跟着他看那张图。

⑤ 表目的/方向的表达

*I'd want to see price reach for this previous day low.*
*I'd be looking for previous day high to be taken.*
  • reach for = 伸手够取，用在\"价格去够某个位\"非常形象。
  • look for + 名词 + to be done = 寻找/期望某事被完成。

⑥ 表达\"理想状态下\"的虚拟语气

*I ideally want to see price close below this up close candle.*
  • ideally 开头修饰整句，表示\"最理想的情况是……\"，是作者表达\"首选剧本\"的常用词，后面往往跟着实际走势作为对照。

⑦ 转折连词表对比

*However, with the structure being bearish, I ideally want to see price close below this up close candle.*
  • However 表转折。with + 名词 + being + 形容词 是独立主格结构，表\"由于/鉴于……\"，让句子更紧凑。

⑧ 表达\"即使…也不一定…\"

*Even though I had a bias for almost every day here, it does not mean that I will find an entry each and every day.*
  • Even though + 从句 = 尽管……；it does not mean that + 从句 = 这并不意味……。用来提醒\"有偏向 ≠ 一定有交易机会\"，是风险管理心态的表达。

五、实例复盘（本集重点）

例 1 — 趋势定义：反复吃同一侧的前日高低点

作者先给定义：上涨趋势 = 反复吃前日高点，下跌趋势 = 反复吃前日低点。

  • 上涨侧：有 PD 阵列（摆动点序列）支撑价格走高，于是预期价格不断够前日高点——标出来看，前日高点被够了一次、两次、三次，一直重复。这就是\"在上涨\"的铁证。
  • 下跌侧：价格一直下跌，预期前日低点被扫掉；如果中间有一个 FVG，价格会先回进它再继续走低。

实例配图：上涨趋势反复吃前日高点

图上可以看到一列向下的 PD 阵列（摆动点序列）在下方支撑价格走高，每次回踩都更高，而前日高点（上方横线）被反复够到。读图要点：只要每次回调的低点都比上一次高，且前日高点不断被吃，趋势就是向上的。

实例配图：下跌趋势反复吃前日低点

价格一路走低，前日低点（下方横线）被一遍遍扫掉。读图要点：下跌趋势里每次反弹的高点都更低，且前日低点不断被吃，这就是\"向下趋势\"的确认。

实例配图：趋势中的公允价值缺口（FVG）

在下跌途中，这次没能直接吃掉前日低点，因为前面留下了一个 FVG。价格会先回进这个缺口再继续向下。读图要点：FVG 像一块\"吸铁石\"，趋势中途会回踩它再续趋势——它不是反转信号，而是中继。

例 2 — 日线第一问：今天够高还是够低？

作者强调：打开日线图，先问自己\"价格更可能够到前日高点还是前日低点\"。能回答就有 DOL 和目标，再降到小级别找 POI 框入场。

  • 补充工具：位移 / 位移缺失。没能位移越过前日高点 → 向下偏向，找前日低点；没能位移跌破前日低点 → 偏向往回够进区间。
  • 快速例子：前日高点没能位移越过 → 框反转 → 次日前日低点成为被吸引的流动性。

实例配图：日线第一问——够高还是够低

日线图上标着前日高点和前日低点两条横线。读图要点：这一问的答案就是当天的 DOL 和 Target。答对方向，你才谈得上下一步小级别找入场。

实例配图：无法位移越过前日高点

价格冲到前日高点附近却没能强势位移越过它（K 线实体无力突破），于是判定向下偏向，目标锁定前日低点。读图要点：\"位移缺失\"等于\"上攻乏力\"，是看跌的早期信号。

实例配图：在前日高点框定反转

前日高点处未能位移越过，在这里框定反转，于是下一天前日低点成为被吸引的流动性。读图要点：反转框定后，跟随方向找对面的前日高低点作 DOL。

实例配图：前日低点框定反转后想看前日高点

反向情形：这里框定反转、无法位移跌破前日低点，于是想看前日高点被够。读图要点：位移打不动哪一侧，方向就偏向另一侧。

例 3 — 只回看 3 天 + 标记延伸制造共振

作者回看前日高低点最多 3 天。把这些线标出来并延伸，能增加共振——比如价格偏离到前日低点下方、回到区间后，重新测试前日低点再继续走高（配合箱体 setup 视频的偏离回测思路）。

实例配图：只回看前 3 天

图上有两个对照：当前天往前 3 天，标出这段时间的前日高低点。读图要点：不用把历史所有高低点都画出来，只看最近 3 天，保持图表干净、聚焦近期关键位。

实例配图：偏离 + 回测前日低点（共振）

价格先偏离跌破这个前日低点（假突破扫损），又回到区间里，随后重新测试这个前日低点再继续走高。读图要点：偏离后的回测是一个高质量入场结构，线标得越清晰越容易抓。

例 4 — 纳斯达克日线：逐日找偏向

作者在纳斯达克日线上一日一日过：

  • 很激进的向上位移 → 找前日高点被吃；吃掉、收盘越过 → 想再看前日高点被吃；位移越过 FVG 和前日高点 → 想再看它被吃……
  • 后来吃了前日高低点、阴线收盘、回进日线 FVG → 转向想看前日低点。
  • 前日低点下方有激进位移 → 想看前日低点；虽有阳线收盘但回进日线 FVG 且向下位移 → 想法没变，想看更低、够到等低点；最后够到前日低点 + 前低，收盘回区间。

实例配图：激进向上位移 → 看前日高点

日线出现一根强势大阳线（激进位移），于是预期前日高点会被吃掉。读图要点：位移越\"暴力\"，后续去够目标（前日高点）的概率越大。

实例配图：激进向下位移 → 看前日低点

在前日低点下方出现激进向下位移，于是想看价格够到前日低点。读图要点：方向反过来同理——暴力下跌后，目标是更低的前日低点。

实例配图：收盘跌穿阳线收盘蜡烛，验证订单块

尽管有一根阳线收盘蜡烛，但结构看跌，作者希望价格收盘跌穿它，把它验证为订单块。读图要点：不要看到阳线就转多，要看它是否被后续收盘跌穿——跌穿了才是可用的订单块。

实例配图：扫完低点后，等前日高点或横盘

扫掉这些低点后，理想剧本是价格够到前日高点，或者至少获得某种横盘整理。读图要点：扫损之后目标会被重新定向——要么去对面，要么先歇一歇。

重要提醒：作者明说，即便几乎每天都看空，也不代表每天都能找到入场。偏向 ≠ 每天都有交易机会。

例 5 — 周一 New York 开盘：吸筹-操纵-派发（AMD）到前日高点

作者回到周一。标出新一周开盘缺口 + 其后续侵占 + 前日高点（本日 DOL）。进纽约开盘前，价格横盘走过亚盘和伦敦，然后向下操纵——这是吸筹阶段，于是预期派发向上进入前日高点。降到小级别：

  • 看到一个5 分钟 FVG，在 FVG 入场，止损设在低点，目标这个高点，风险回报约 2R。
  • 价格先回进区间偏离，再走高，从新一周开盘缺口后续侵占处被拒绝，最后扩展到前日高点——一个完整的自上而下（top down）例子。

实例配图：纽约开盘前的吸筹-操纵

价格横盘走过亚盘、伦敦，然后在纽约开盘前向下操纵扫损。读图要点：这是 AMD 的\"吸筹+操纵\"阶段，派发方向应与操纵相反——即向上进前日高点。

实例配图：5 分钟 FVG 入场，约 2R

小级别上出现一个 5 分钟公允价值缺口，在此入场、止损放低点、目标前日高点，风险回报约 2R。读图要点：扫损后的回踩 FVG 是最干净的入场，R 比清晰才好控制仓位。

实例配图：回测偏离后扩展到前日高点

价格先回进区间偏离，从新一周开盘缺口后续侵占处被拒绝，然后向上扩展到前日高点。读图要点：\"回测偏离→拒绝→扩展\"是一套完整的多单剧本，目标锁定前日高点 DOL。

例 6 — 后续两天：DOL 已被亚盘吃掉 → 放弃该时段

  • 第二天：标出前日高点，降到小级别——亚盘已经吃掉前日高点，既然 DOL 已被吃，作者对纽约时段不再感兴趣（但订单流仍延续向上进纽约上午）。
  • 第三天：伦敦基本横盘、吃掉高点又向下吃初始低点；接近纽约上午时向上走一点，然后 8:30 新闻向下操纵。回到 AMD 思路：吸筹+操纵 → 想看派发进前日高点。小级别上想先看收盘跌破 8:30 开盘价 + 一连串阴线收盘，再等对操纵的回测，最后打到前日高点，完成 AMD。

实例配图：8:30 新闻向下操纵

接近纽约上午时价格走高一点，然后 8:30 新闻数据向下操纵扫损。读图要点：高影响数据常制造\"操纵\"，之后方向与操纵相反（派发进前日高点），是 AMD 剧本的一部分。

实例配图：亚盘已吃掉前日高点

下一天开盘，亚盘在起始阶段就吃掉了前日高点。读图要点：如果只用前日高低点作 DOL，而它已被亚盘吃掉，就该放弃后续时段——DOL 没了，就别硬找。

七、给 HYPE 实战的落地要点（我的延伸）

对照你在 HYPE 15 分钟上的玩法，这一集可以直接搬过去：

1. 每天开盘先问第一问：\"今天价格更可能够到昨天的 15m 高点，还是低点？\" 答案就是你的 DOL 和目标。HYPE 15m 上直接标出前一日高点/低点两根横线。

2. 用趋势判方向：HYPE 15m 上如果每次回调低点都更高、且前日高点不断被吃 → 今天继续盯前日高点；反之盯前日低点。

3. 位移缺失 = 转向信号：价格冲到前日高点/低点附近却无力位移越过 → 立即警惕反转，把目标换到对侧。

4. 只回看 3 天：别把所有历史高低点都画满屏幕，只看最近 3 天的前日高低点，图干净才好决策。

5. AMD 剧本：结合你的时段，如果开盘前/早期出现向下操纵（假跌破扫损），大概率要派发向上进前日高点——派发方向永远与操纵相反。

6. 8:30 新闻（北京 20:30）警惕操纵：高影响数据点前后常出扫损假动作，别在操纵中途追单，等回测（box setup 的偏离回测）再进。

7. DOL 已被扫掉就放弃：如果亚盘/前一时段已经吃掉你的前日高低点，这个 DOL 就不成立了——别硬等，直接放弃该时段，这也是作者反复强调的纪律。

8. 配合 2R 目标：扫损后的 5m FVG 回踩是最干净入场，止损放低点、目标前日高低点，先算清 R 再下单。

建议：把\"今日 DOL（前日高点 or 低点）\"和\"该 DOL 是否已被吃掉\"写进交易日志头部。每天开盘两行字，慢慢就会养成\"先定 DOL、再找入场\"的纪律盘感。

本集小结

  • 核心：价格不横盘，就够昨天的高或低。涨势反复吃前日高点，跌势反复吃前日低点。
  • 流程：日线问第一问 → 定 DOL 和目标 → 降到小级别找 POI（FVG/订单块）→ 回踩入场 → 目标前日高低点。
  • 纪律：DOL 已被扫掉就放弃；有偏向 ≠ 每天都能找到入场。
