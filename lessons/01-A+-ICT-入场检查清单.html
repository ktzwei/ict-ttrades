A+ ICT Entry Checklist — 中英对照学习笔记

来源：TTrades — *A+ ICT Entry Checklist*（10:50）
概念定位：这是整个 ICT 体系里「入场前最终检查」的一集——有了 bias 之后，用什么标准确认「这一单可以打」。

---

一、核心思想（先看这个）

这一集讲的是入场清单。作者的原话逻辑是：

一旦我有了每日偏向（daily bias）或方向感，我就会用这份清单来确认，在下单之前，所有必要条件是否都满足了。

换句话说：不是看到机会就进，而是按顺序核对四个条件，全部满足才动手。这四件事是：

顺序检查项通俗含义
①Stop raid（止损扫单）低点被扫掉/跌破前，先有个低点被埋在这里
②Market structure shift / displacement（结构转换/位移）前一个高点被突破，并且被强势推过去
③Discount（回到折扣区）价格回踩到某个价格范围的「折扣段」
④PD array（订单递送区）这里有个 FVG、订单块、OTE 或 breaker block 可供入场
一句话记住：先扫止损 → 结构转多 → 回踩折扣区 → 在 PD array 里进场。四步缺一，就不打。

三、中文翻译

大家好。这期视频讲的是我的 A+ 级 ICT 入场清单。

一旦我有了每日偏向或方向感，我就会用这份清单来确保，在我入场之前，所有必要条件都满足了。我们先看一下清单内容，然后看几个实例。

这份清单里我关注几件事——我们按顺序过一遍。

第一件事是「止损扫单」（stop raid）。 意思就是：在低点被扫掉或跌破之前，先有一个低点被埋在这里。

第二件事是「市场结构转换或位移」（MSS / displacement）。 意思是：前一个高点被突破了，并且价格被强势地推过去。

第三件事是寻找「有一点弹性」的地方。 我一般希望看到价格回踩到某个价格范围的折扣段（discount）。

第四件事是寻找某种「订单递送区」（PD array）。 通常我倾向于要一个公允价值缺口（FVG）或订单块（order block），但在这个区域我也会用 OTE，以及 breaker block。

我知道刚才有点乱，所以我把它展开，逐个展示。这些概念每一个都可以单独作为入场模型。不过我个人喜欢把这些概念两两、甚至三三组合在一起，形成自己的策略。

比如，我会在最优交易入场区（OTE）里找公允价值缺口，或者在 OTE 里找 Box 模型。组合的方式有很多，我就是挑最顺眼的来做。

我们进入一些实例，我会逐个展示这些概念，或者把它们组合起来。第一个例子，我们看纳斯达克 15 分钟图，观察价格行为，直到触及这个日线公允价值缺口的回补。所以当我们让这个走出来，我们首先要注意到的是，这里停着卖方流动性，当价格进入那个水平。你可以看到我们对它做出了漂亮的反应。但是，结构转换了吗？还没有。随着下一根 K 线，我们转换了结构。所以我们有了那个卖方流动性或止损扫单，以及我们的结构转换。

现在我要寻找一个入场模型。所以我们逐个概念过一遍——第一个是折扣和溢价。所以理想情况下，在这个位移区间里，我不会在 0.5 上方追得太久。我想在下面这段绿色区域做多。用 OTE 再进一步，我可以看到这是我们上面的溢价区，我在那里不想做多，这把我的折扣区收窄到这里的 OTE。

接下来我可以找的是一个公允价值缺口，这里有一个非常小的，以及一个订单块，就是这里这根向下收盘的 K 线，然后 breaker block 就是扫流动性之前这几根向上收盘的 K 线。最后，对于 Box 模型，我会寻找价格进入这个区域。

正如你所见，所有这些概念都呈现出来了。我怎么选择在哪里入场？这归结为风险回报比，以及什么最顺眼。我知道当我把我入场点移近我的止损时，我的风险回报比会增加。然而，我走得越远，也有可能在这次交易中无法成交。所以我努力做的，是在风险回报比、什么顺眼、以及先进场之间找到平衡。

所以如果我在看这笔交易，我会怎么做？第一件事是标出我的 OTE，然后我就在这个区域附近寻找一个 PD 数组。我在里面看到了什么？我有一个公允价值缺口，它嵌套在这个订单块里。这也和 Box 模型对齐。所以对我的入场，我个人会看向在这里进场。我的止损放在这个低点，第一次部分止盈在这里，然后看向上方的买方流动性。

让这个走出来，那会是我的部分止盈，然后取决于我是否把止损移到保本，它就会击中上方的买方流动性。

下一个例子，我在看这个区间。 我们在这个区间的高溢价处，同时也是这个向下位移区间的溢价处，而且这些相对等的低点都停在下边。所以我们深入看看。我们在五分钟图上，如果你想暂停一下看看你看到了什么，尽管暂停。

我注意到的第一件事是，我们有买方流动性停在这里，我们一直在消耗它。我们有一个向上的移动，从那里有一个激进的移动。所以如果我们看这个结构，我们有一个高点、低点、更高的高点。所以我在这里注意到的是这个 breaker block。我注意到的下一件事是，那个 breaker block 里面有什么——有一个公允价值缺口停在这里。所以我想看到的是价格回到这个 breaker block，最多进到里面的公允价值缺口。所以看它，如果我只是做 breaker block 入场，会是这样的。然而，如果我要收窄到公允价值缺口，会是这样的。让这个走出来，如果我太贪心去够我之前谈到的那些低点，会是这样的。你可以看到我们确实去够了那些低点。

回顾一下这份清单——这里有一个止损扫单，这里有一个市场结构转换，回到一个带 PD 数组的溢价区，然后才走开。下一个例子，我们看 ES 一分钟图。 你会注意到，这里有一个高点停着。你可以看到我们突破了这个高点，我们收回来，目前 K 线实体正在尊重这个水平。这里是我们的止损扫单，这里是我们的结构转换。我现在在找什么？我在找 PD 数组、在 OTE 里、或者在溢价区。当这个低点被打出来，如果那是我们的低点，就画出斐波那契，我在这里这个区域有什么？嗯，我有一个 breaker block 和一个公允价值缺口。让这个走出来，价格向上触及、回补那个公允价值缺口，冲进 OTE，然后继续走低。我的风险大概是这样的。

如果我们去五分钟图看完全相同的例子，这是同一个 setup，但看起来有点不一样。所以你会注意到这里，我们有这个高点或这个高点，被向上的移动猎取了。我们得到一个向下的激进位移——这是我们的结构转换。然后标出我们的 OTE，我们回踩进一个 OTE。这个区域有什么 PD 数组？嗯，这里有一个订单块。有了它，我的入场会在订单块上，目标是新低，止损在订单块高点。

下一个例子，我们看纳斯达克一分钟图。 你会注意到，我们确实在这个低点下方走了一个 tick，但我个人不把它算进去。但是发生了什么——我们得到这次向上位移。这符合我的标准吗？不符合。我倾向于在位移之前先有止损扫单，所以我不把这个算作一次位移上涨。你看价格倾向于在那里获得支撑，然后跌得更低。所以我现在在处理这个低点。

发生了什么？我们得到一个向这个区间下方的移动，然后又回到区间内。所以激进向下、激进向上——这是偏离区间的动作。然后是累积、操控——我想看到派发。所以理想情况下，我在寻找对这次操控的回测，然后去够这里的另一侧，再向上。我们看看会发生什么。

你注意到这些 K 线没有收在这个旧低点下方——就这样，你向上移动，部分止盈，然后看看会发生什么。我们上方停着所有这些流动性，然后就这样。虽然我们在这次入场之前没有转换结构，但这是一个 Box 模型入场，我想把它放进来只是为了展示：如果在一个移动之前没有低时间框架的流动性猎取，我对它没有兴趣。

最后一个例子，我从日线一路下到五分钟。 所以你会注意到这里，关注位是 ES 上的这个成交量失衡。下到小时图，我们可以看到这里有一个止损扫单、一次位移向上，用斐波那契标出那段位移。我们现在回到小时图上的一个均衡区。下到 15 分钟图——这里是那个均衡区，这里是卖方流动性。看看会发生什么。我们得到一个激进的向下移动，穿过卖方流动性进入关注位，然后我们得到向上的位移。你会注意到，我们确实有一个公允价值缺口。然而，这符合我所有的标准吗？不符合，因为它位于区间的溢价部分。所以从这里，我下到五分钟。我会去掉关注位，这样我们看得更清楚。这里有一个公允价值缺口，如果我们去掉位于溢价区的部分，看起来是这样的。从这里我们有订单块、公允价值缺口。所以我会看向在这里入场，把止损放在这个订单块低点，部分止盈或把止损移到保本，目标是早盘的初始高点，然后让利润奔跑。

让这个走出来——这里是入场，被尊重，然后我们向上位移。

回顾所有内容——寻找一个止损扫单、一个结构转换、一个回到均衡或 OTE 的回归、某种顺眼的 PD 数组，然后管理我的风险，以获得扎实的风险回报比。我希望你觉得这个视频有用。如果你觉得有用，请考虑点赞和订阅。祝你今天愉快。再见。

4.2 本集英文语法与表达整理

这集讲入场检查，语速快但结构清晰，几个值得学的表达：

① 表"顺序推进"的「we'll go through them in order」

*We'll go through them in order.*
  • go through + 名词 = "逐一过一遍/检查"，讲解清单、列表时的常用动词短语。
  • in order = "按顺序"。整句：我们按顺序把它们过一遍。

② 表"确保"的「make sure」

*I will use this checklist to make sure all requirements are met before I take an entry.*
  • make sure + that 从句 = "确保……"，注意 that 常省略。
  • before I take an entry：before + 从句表"在……之前"，是入场条件的时间逻辑。
  • 整句：我会用这份清单确保所有条件满足后再入场。

③ 表"偏好/倾向"的「prefer to」

*I prefer to have a fair value gap or an order block.*
  • prefer to do = "更倾向于做某事"，表个人取舍。
  • 同段还有 I would also use an OTE（我也会用 OTE）、I'd want to be longing（我想做多）——would 表委婉/意愿。

④ 表"逐步收窄"的递进表达

*Taking that one step further by using an OTE, I can see...*
  • taking that one step further = "再进一步"（成语化表达），用于逻辑递进。
  • by using an OTE：介词 by + 动名词表"通过……方式"。

⑤ 表"平衡取舍"的「find a balance between」

*I try to find a balance between risk to reward and just getting into the trade.*
  • find a balance between A and B = "在 A 和 B 之间找平衡"，交易风控讲解的高频表达。
  • 整句：我努力在"风险回报比"和"先进场"之间找平衡。

⑥ 表"叠加/嵌套"的「be nested within」

*This fair value gap is nested within this order block.*
  • be nested within = "被嵌套在……内部"（本义是"套娃"），描述 PD array 叠加关系。
  • 整句：这个公允价值缺口嵌套在这个订单块内部——这是高置信入场的关键信号。

五、实例复盘（6 个实战例子）

作者在视频里用 6 个实例，把同一套清单在不同品种、不同周期上跑了一遍。核心不变，画面略有差别。

例 1 — NASDAQ 15 分钟（完整清单走一遍）

  • 价格接近一个日线 FVG 缺口，下方有卖方流动性 resting（挂在下方）。
  • 价格扫掉卖方流动性，做出反应，但还没转结构。
  • 接下来一根 K 线结构转换——卖方流动性 = stop raid，出现结构位移。
  • 然后作者开始找入场模型：
  • 折扣/溢价：位移区间不追高过 0.5，只在绿色（折扣）段做多；
  • OTE 进一步把折扣区收窄到 0.618–0.79；
  • FVG：这里有个很小的缺口；Order block：那根下收的 K 线；Breaker block：扫流动性之前的那几根上收 K 线；
  • Box setup：价格回踩进这个区域。
  • 如何取舍：入场越贴近止损，风险回报比越高，但也越可能成交不了。作者在「风险回报」和「能不能成交」之间找平衡。
  • 实际操作：先标 OTE，再在附近找 PD array——这里是 FVG 嵌套在 order block 里，又和 Box setup 重叠。入场就在这块，止损放在这个低点，先平一部分，目标看上方买方流动性。

实例配图：例 1 完整入场

图中标好 OTE（0.618–0.79 折扣带），找到嵌套的 FVG + Order block，与 Box 重叠处就是入场点，止损放低点，先平一部分，目标看上方买方流动性。这是一张"清单四步全走完"的总图。

实例配图：例 1 的三个 PD array 并列

同一个位移区间里，FVG（小缺口）、Order block（下收 K 线）、Breaker block（上收 K 线）三者并列。例 1 的核心就是在这几个叠加处挑最顺眼的一个进。

例 2 — 5 分钟（Breaker block + FVG）

  • 上方有买方流动性，价格从这里强势拉离（aggressive move）。
  • 结构：低点-低点-高点-高点（higher low, higher high）。
  • 注意到这里有个 breaker block，里面还嵌套一个 FVG。
  • 期待价格回到 breaker block，最好再进到里面的 FVG。
  • 纯 breaker 入场 vs 收窄到 FVG 入场——后者更精准。
  • 结果：价格回踩，扫到那些低点。

实例配图：例 2 的 Breaker block 内嵌 FVG

Breaker block 里还挂着一个 FVG。期待价格回踩 breaker block，最理想是插进里面那个 FVG。收窄到 FVG 入场比纯 breaker 入场更精准。

例 3 — ES 1 分钟（stop raid + OTE + FVG）

  • 上方有个高点，价格突破高点、又收回，K 线实体贴着这个位。
  • stop raid 出现 → 结构转换。
  • 等这个低点确认后，拉 FIB：这块有个 breaker block + FVG。
  • 价格上冲补掉 FVG，进到 OTE，然后继续下走。

实例配图：例 3 的 Breaker block 内 FVG

等低点确认后拉斐波那契，这个区域有 Breaker block + FVG。价格先上冲补掉 FVG、进到 OTE，随后继续下走。这是 stop raid + 结构转换后的 FVG/OTE 接力。

例 4 — 同例换到 5 分钟（看同一 setup 的不同长相）

  • 高点被扫，然后强势位移向下（displacement），这是结构转换。
  • 标 OTE，价格回踩进 OTE。
  • 区域里有个 order block，入场就放这，目标新低，止损在 order block 高点。

实例配图：例 4 的 Order block 入场

同一 setup 换到 5 分钟：高点被扫后强势位移向下（结构转换），标 OTE 价格回踩进去。区域内有个 order block，入场放这，目标新低，止损放 order block 高点。

例 5 — NASDAQ 1 分钟（Box setup 入场）

  • 有个低点被扫了一根 tick，但作者不数它——因为它没有满足「stop raid 先于位移」的条件。
  • 价格跌破区间又拉回，形成累积-操控-派发（AMD）节奏。
  • 理想情况：回踩操控（manipulation）段，再去够区间另一侧。
  • 关键观察：K 线不收盘跌破旧低点，然后向上突破。上方全是流动性。
  • 作者强调：这个入场之前没有转结构，是纯 Box setup 入场——但它的意义在于：如果低位没有先扫流动性，作者对这个 setup 没兴趣。

实例配图：例 5 的 Box setup 入场实况

K 线不收盘跌破旧低点，随后向上突破、扫掉上方流动性。这是纯 Box 模型入场——入场前没有转结构，用来演示"低位没先扫流动性就别碰"的反面教材。

例 6 — 从日线一路下到 5 分钟（多周期收敛）

  • 日线：关注位是一个成交量失衡（volume imbalance）。
  • 小时线：有 stop raid + 位移向上，拉 FIB，价格回踩到均衡区（equilibrium）。
  • 15 分钟：找到均衡区 + 卖方流动性，价格强势下破、扫到关注位，再位移拉回。这里有个 FVG，但在溢价区，不满足全部条件。
  • 5 分钟：去掉 POI 看得更清楚，有个 FVG + order block，在非溢价区。
  • 入场：进在这里，止损放 order block 低点，先部分止盈或移到保本，目标看早盘高点，剩下的让利润奔跑。

实例配图：例 6 从日线一路下到 5 分钟

日线的成交量失衡关注位 → 小时图 stop raid + 位移 + 回踩均衡区 → 15 分钟下破扫关注位再拉回。多周期一路收敛到低级别，是"顺 DOL 一路往下找入场"的标准示范。

实例配图：例 6 的 5 分钟入场

去掉 POI 看得更清楚：5 分钟有个 FVG + order block，在非溢价区。入场进这里，止损放 order block 低点，目标看早盘高点，剩下的让利润奔跑。

七、给 HYPE 实战的落地要点（我的延伸）

对照你在 HYPE 15 分钟上的玩法，这一集可以转成一条硬规则：

1. 没扫单（stop raid），不碰——尤其别在位移之前进场。

2. 结构没转（MSS），不急——突破要「强势推过去」，不是小步磨蹭。

3. 只在折扣/均衡区做多，不追溢价。

4. 入场必须落在某个 PD array 上（FVG / order block / OTE / breaker 至少占一个）。

5. 多个 PD array 重叠的地方，就是高置信入场位。

建议：下次在 HYPE 15m 图上，把这四条当成入场前的硬性 checkbox，全部打勾再考虑下单。
